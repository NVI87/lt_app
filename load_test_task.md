Нагрузочное тестирование сервиса ЕТЛ

Скрипты:
1) kkafka.py - берет csv с событиями топика и отправляет в топик
2) os_index_lt_chunks.py - читает индексы из списка и печатает их каунт в csv каждую секунду
3) err_topic_consumer.py - читает топик ошибок и пишет в json файлы в заданную директорию
4) etl_file_stats.py - Скрипт для сбора статистики по JSON-отчётам ETL пайплайна индексации.  Пишет таблицу в csv
5) etl_extrapolate.py - делает экстраполяцию и отчет по файлу результату etl_file_stats.py

Примеры файлов:
1) export-ppwi-ii-migration.csv, export-lt-all-types-1.csv - файлы с событиями идущими в ЕТЛ, обрати внимание на уникальные ключи
2) index_counts_release301-0.csv - результат каунтера индексов (os_index_lt_chunks.py)
3) примеры исходящих файлов err_topic_consumer.py (они же входящие для etl_file_stats.py) в директории err_events
4) stats_done.csv, stats_skipped.csv - пример результата etl_file_stats.py
5) etl_extrapolate.py не запускался, примеров нет

Задача:
1) объединить скрипты в некий питон сервис, настраивающий и запускающий их.
2) вытащить настраиваемые параметры всех скриптов в отдельный единый конфиг

Комментарии:
1) kkafka.py. Настраиваются параметры продюсера, консьюмера (сервера, топик, группа) и файл из которого считываются события. 
Запись в топик производить нужно с подпором по оффсету консьюмера (группа совпадает с диагностируемым ЕТЛ сервисом) и настройкой максимальной величины лага
2) os_index_lt_chunks.py - настройки названий индексов, параметров соединения с опенсерч, названия файла вывода
3*) сервис в который все объединяем завернуть в streamlit приложение с выводом окон редактирования настроек 
и кнопкой старт/стоп для каждой подзадачи, а также с возможностью выгружать конфигурацию в ямл файл и подкидывать 
ямл файл с настройками в него. Также надо предусмотреть режим "провеедение нагрузочного тестирования", также запускающийся по кнопке старт/стоп и принимающий при запуске
в окошке некие description о заходе тестированияи формирующий итоговый отчет по всем артефактам - результату запущенных в пределах сессии тестирования все подзадачи
